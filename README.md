A 3D open-world game in the style of GTA, set in the neon city of Neon Bay. You play Jax Marlowe, a getaway driver working for Mara Voss, across 6 story missions — driving and on-foot gameplay, live traffic, a police wanted system, combat, a HUD with minimap, synth audio (WebAudio), and save progress via localStorage.

## How to run

```sh
node main.ts
```

To serve the game locally:

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome.
